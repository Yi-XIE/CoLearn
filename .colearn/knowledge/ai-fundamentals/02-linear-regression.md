# 第2章：线性回归 — 最简单的机器学习

## 核心思想

找一条直线（或超平面），让它尽可能贴近所有数据点。

## 数学表达

预测值：y = wx + b

- w：权重（斜率）
- b：偏置（截距）
- x：输入特征
- y：预测输出

多维情况：y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

## 损失函数

均方误差（MSE）：L = (1/n) Σ(yᵢ - ŷᵢ)²

目标：找到 w 和 b，使得 L 最小。

## 梯度下降

找最小值的方法：沿着损失函数下降最快的方向走。

```
重复直到收敛：
  w = w - α × ∂L/∂w
  b = b - α × ∂L/∂b
```

α 是学习率（步长）：
- 太大：跳过最优解，震荡不收敛
- 太小：收敛太慢
- 合适：稳步下降到最优

## Python 实现（5行核心代码）

```python
import numpy as np

# 数据
X = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 6, 8, 10])

# 训练
w, b, lr = 0.0, 0.0, 0.01
for _ in range(1000):
    pred = w * X + b
    w -= lr * (-2/len(X)) * np.sum(X * (y - pred))
    b -= lr * (-2/len(X)) * np.sum(y - pred)

print(f"y = {w:.2f}x + {b:.2f}")  # y ≈ 2.00x + 0.00
```

## 什么时候用线性回归

适合：
- 预测连续值（房价、温度、销量）
- 特征和目标之间大致是线性关系

不适合：
- 分类问题（用逻辑回归）
- 非线性关系很强的数据（用多项式回归或神经网络）

## 从线性回归到神经网络

线性回归是神经网络的最小单元。一个没有激活函数的单层神经网络就是线性回归。加上非线性激活函数，就能拟合任意复杂的函数。
