# 第3章：神经网络基础

## 从生物神经元到人工神经元

生物神经元：接收信号 → 加权求和 → 超过阈值就激活 → 传递给下一个神经元

人工神经元：输入 × 权重 → 求和 + 偏置 → 激活函数 → 输出

## 感知机（Perceptron）

最简单的神经网络，只有一个神经元：

```
输出 = 激活函数(w₁x₁ + w₂x₂ + ... + wₙxₙ + b)
```

能解决线性可分问题（AND、OR），不能解决 XOR。

## 多层感知机（MLP）

堆叠多层神经元，解决非线性问题：

```
输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层
```

每一层的每个神经元都与下一层的所有神经元相连（全连接）。

## 激活函数

为什么需要：没有激活函数，多层网络等价于单层（线性组合的线性组合还是线性）。

常用激活函数：

| 名称 | 公式 | 特点 |
|------|------|------|
| Sigmoid | 1/(1+e⁻ˣ) | 输出 0-1，用于二分类输出层 |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 输出 -1 到 1，零中心 |
| ReLU | max(0, x) | 简单高效，现代网络默认选择 |
| Softmax | eˣⁱ/Σeˣʲ | 多分类输出层，输出概率分布 |

## 反向传播（Backpropagation）

训练神经网络的核心算法：

1. **前向传播**：输入数据，逐层计算，得到预测值
2. **计算损失**：预测值与真实值的差距
3. **反向传播**：从输出层往回，用链式法则计算每个参数的梯度
4. **更新参数**：用梯度下降更新所有权重和偏置

```
前向：x → h₁ → h₂ → ŷ → Loss
反向：Loss → ∂L/∂ŷ → ∂L/∂h₂ → ∂L/∂h₁ → ∂L/∂w
更新：w = w - lr × ∂L/∂w
```

## 关键超参数

| 超参数 | 作用 | 调参建议 |
|--------|------|----------|
| 学习率 | 每步更新的幅度 | 从 0.001 开始，观察 loss 曲线 |
| 层数 | 网络深度 | 从 2-3 层开始，逐步加深 |
| 每层神经元数 | 网络宽度 | 通常 64/128/256/512 |
| Batch size | 每次用多少样本计算梯度 | 32 或 64 是常见起点 |
| Epochs | 遍历整个数据集的次数 | 观察验证集 loss 不再下降时停止 |

## 过拟合与正则化

过拟合信号：训练 loss 持续下降，验证 loss 开始上升。

对策：
- **Dropout**：训练时随机关闭一部分神经元
- **L2 正则化**：在 loss 中加入权重的平方和
- **早停（Early Stopping）**：验证 loss 不再改善时停止训练
- **数据增强**：人为扩充训练数据
