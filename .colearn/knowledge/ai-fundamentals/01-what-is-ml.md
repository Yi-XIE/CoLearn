# 第1章：机器学习是什么

## 定义

机器学习（Machine Learning）是人工智能的一个分支，它让计算机能够从数据中学习规律，而不需要被显式编程。

简单说：**传统编程是人写规则，机器学习是机器从数据中发现规则。**

## 三种学习范式

### 1. 监督学习（Supervised Learning）

给机器"带答案的题目"，让它学会从输入推断输出。

- 输入：特征（features）
- 输出：标签（labels）
- 例子：给 1000 张猫狗图片（带标注），让模型学会区分猫和狗

典型算法：线性回归、逻辑回归、决策树、SVM、神经网络

### 2. 无监督学习（Unsupervised Learning）

给机器"没有答案的数据"，让它自己发现结构。

- 输入：只有特征，没有标签
- 目标：发现数据中的模式、分组、异常
- 例子：给 10000 个用户的购买记录，自动分成几类用户群体

典型算法：K-Means、PCA、自编码器

### 3. 强化学习（Reinforcement Learning）

让机器在环境中试错，通过奖励信号学习最优策略。

- 输入：环境状态
- 输出：动作
- 反馈：奖励或惩罚
- 例子：AlphaGo 通过自我对弈学会下围棋

## 机器学习的工作流程

```
1. 收集数据 → 2. 数据预处理 → 3. 选择模型 → 4. 训练 → 5. 评估 → 6. 部署
     ↑                                                          |
     └──────────────── 如果效果不好，回到第2或第3步 ──────────────┘
```

## 关键概念

| 概念 | 含义 | 类比 |
|------|------|------|
| 训练集 | 用来学习的数据 | 课本上的例题 |
| 测试集 | 用来检验的数据 | 考试题 |
| 过拟合 | 模型记住了训练数据但不能泛化 | 只会做原题不会做新题 |
| 欠拟合 | 模型太简单，连训练数据都学不好 | 基础太差，例题都做不对 |
| 特征 | 描述数据的属性 | 一个人的身高、体重、年龄 |
| 标签 | 我们想预测的目标 | 这个人是否患有某种疾病 |

## 为什么现在机器学习这么火

三个条件同时满足：
1. **数据**：互联网产生了海量数据
2. **算力**：GPU 让大规模计算成为可能
3. **算法**：深度学习等新方法突破了性能瓶颈
